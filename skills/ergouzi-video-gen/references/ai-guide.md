# Optional Video AI Guide

This file is advisory only. Do not load it for routine execution. Read it only
when the user asks which model to choose or how to improve a prompt. Never let
this guidance override an explicit model, prompt, or parameter.

- Start with `e-video` for general text-to-video, image-to-video, or
  audio-conditioned generation.
- Use `e-video-animate` when a source video supplies motion for a reference image.
- Use `e-video-avatar` for portrait speech or lip sync.
- Use `e-video-replace` when the source scene and motion must remain while one
  or more people are replaced.

For transformations, state what may change and what must remain. Prepare input
media at the intended aspect ratio because several models inherit framing from
the source image or video.
