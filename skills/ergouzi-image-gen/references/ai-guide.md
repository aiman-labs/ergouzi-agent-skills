# Optional Image AI Guide

This file is advisory only. Do not load it for routine execution. Read it only
when the user asks which model to choose or how to improve a prompt. Never let
this guidance override an explicit model, prompt, or parameter.

- Start with `e-image` for inexpensive general generation.
- Prefer `e-image-ideogram` when accurate text, posters, or deliberate layout
  matters more than minimum cost.
- Use `e-image-edit` when existing pixels or identity must be preserved.
- Use `e-image-try-on` only for clothing transfer from reference garments.
- Use `e-image-upscale` only to enlarge an existing image.

For edits, describe what changes and list what must stay unchanged. For
generation, keep exact user-provided text verbatim and distinguish visual scene
instructions from negative constraints.
